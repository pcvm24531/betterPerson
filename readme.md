1. CONTEXTO DEL PROYECTO (¿Por qué estamos construyendo esto?)
--------------------------------------------------------------------------------
El mercado actual de aplicaciones de desarrollo personal y "habit trackers" está saturado de herramientas basadas en la productividad extrema y la gamificación tóxica. La mayoría de estas apps dependen de "rachas" (streaks) y castigan visual o psicológicamente al usuario cuando falla un día. Esto genera el "Efecto de Todo o Nada": el usuario se frustra, siente culpa y termina abandonando la aplicación.

MicroKaizen nace como una respuesta a este problema. Es una aplicación fundamentada en la Terapia Cognitivo-Conductual (TCC) y el diseño conductual compasivo. Creemos que la verdadera transformación personal no ocurre por presión, sino mediante pequeños pasos consistentes (fricción mínima) y un entorno que fomente el perdón y el autoconocimiento cuando hay tropiezos.

2. OBJETIVO PRINCIPAL (¿Qué queremos lograr?)
--------------------------------------------------------------------------------
Crear un "Santuario Personal" digital que ayude a los usuarios a mejorar continuamente como personas a través de un sistema de Micro-Hábitos Semanales. 

El objetivo es dual:
A) Ayudar a superar debilidades conductuales (procrastinación, impaciencia, falta de constancia).
B) Potenciar habilidades, virtudes y hábitos positivos (desarrollar resiliencia, mejorar el enfoque, cultivar la gratitud).

Buscamos generar una alta retención orgánica mediante una experiencia de usuario (UX) que alivie la carga cognitiva, celebre el progreso real y despierte la curiosidad por seguir creciendo.

3. PRINCIPIOS FUNDAMENTALES (Las reglas innegociables del equipo)
--------------------------------------------------------------------------------
Para que la app tenga un impacto 100% positivo, todo el equipo (desarrollo, diseño, producto) debe respetar estos pilares:
- Cero "Rachas" o Streaks: No contamos días consecutivos. Medimos la "Tasa de Consistencia" (ej. 5 de 7 días).
- Días de Gracia: El sistema permite al usuario tomar descansos sin perder su progreso ni sentir culpa. Fallar un día es recolección de datos, no un fracaso.
- Ley de Fricción Mínima: Cualquier micro-hábito sugerido debe poder realizarse en menos de 2 minutos (ej. "Leer un párrafo", no "Leer un capítulo").
- Recompensa Intrínseca: Las notificaciones motivan desde la identidad ("Estás construyendo una mente enfocada") y no con insignias vacías.
- Filtro Ético: Si el sistema detecta patrones de depresión severa o riesgo clínico, debe derivar compasivamente al usuario a líneas de ayuda profesional.

4. LA EXPERIENCIA DEL USUARIO (El Flujo Principal)
--------------------------------------------------------------------------------
1. Diagnóstico Inicial: El usuario chatea con la app de forma amigable para descubrir en qué área quiere trabajar (una debilidad a mejorar o una habilidad a potenciar).
2. Selección con Autonomía: El sistema le ofrece 3 opciones de micro-hábitos para esa área. El usuario elige el que mejor se adapte a su vida y lo "ancla" a una rutina existente.
3. El Reto de 7 Días: El usuario recibe una píldora psicoeducativa diaria (un dato fascinante) y puede marcar su progreso con un solo toque, incluso dejando un emoji de cómo se sintió.
4. Evolución y "Ganas de más": Al día 7, recibe un resumen visual hermoso de su semana. Su progreso ilumina una nueva rama en su "Árbol de Habilidades" o Mapa de Crecimiento, dándole a elegir si consolida el hábito otra semana o avanza al siguiente reto.

5. ALCANCE DEL PROYECTO (MVP - Fase 1)
--------------------------------------------------------------------------------
Lo que SÍ incluye la primera versión (Producto Mínimo Viable):
- Aplicación Móvil (iOS y Android) desarrollada en React Native/Flutter.
- Implementación de Widgets para marcar hábitos sin abrir la app.
- Autenticación básica (Email, Google Sign-In).
- Catálogo inicial cerrado: 3 a 5 áreas de mejora (con 3 opciones de micro-hábito cada una).
- Lógica completa del Reto de 7 Días, cálculo de consistencia y Días de Gracia.
- Modelo de acceso gratuito para validar tracción y medir retención.

Lo que queda diferido para futuras versiones (V2 en adelante):
- Paywall de suscripciones (monetización).
- Catálogo masivo de +50 áreas de desarrollo personal.
- Funciones sociales (Accountability partners o retos compartidos).
- Versión web de escritorio.
